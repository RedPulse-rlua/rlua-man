# rlua — Mobile PWA

Полноценное PWA-приложение rlua, оптимизированное под телефоны и планшеты.

## Возможности
- 📱 Установка на рабочий стол (PWA)
- 📁 Файловое хранилище Lua-скриптов (RLUA)
- 🔐 Многоуровневая обфускация кода
- 🎙 VIZOR — голосовые комнаты (WebRTC)
- 👤 Профиль и настройки безопасности
- 🔧 Админ-панель (управление пользователями, логи)

## Установка
1. Открой `rlua.pages.dev` на телефоне
2. Нажми «Добавить на рабочий стол» в меню браузера
3. Готово — приложение работает как нативное

## Технологии
- Vanilla JS (SPA)
- Service Worker (офлайн)
- WebRTC (голосовые комнаты)
- Cloudflare Workers (бэкенд)
- Cloudflare KV (хранилище)
